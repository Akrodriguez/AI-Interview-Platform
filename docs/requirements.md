# AI Interview Preparation Platform

## Objective
Build an AI-powered interview preparation platform where users can practice coding, technical, and HR interviews with personalized AI feedback.

## Target Users
- College students
- Job seekers
- Software Engineers

## Core Features

### Authentication
- Register
- Login
- Logout
- JWT Authentication
- Password Encryption

### Dashboard
- User Profile
- Progress Tracking
- Interview History

### AI Interview
- Generate Interview Questions
- AI Answer Evaluation
- AI Feedback
- Company Specific Questions

### Coding Practice
- Coding Challenges
- Timer
- Difficulty Levels

### Analytics
- Accuracy
- Weak Topics
- Streak
- Performance Graphs

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
